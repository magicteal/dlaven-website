### 🛡️ Authentication & Authorization Rules
- **Session Mechanism**: Dual authentication token model:
  - Backend sets an `httpOnly` cookie (`token`) on login and register.
  - Frontend stores the JWT in `localStorage` (`dlaven_token`) and injects it as an `Authorization: Bearer <token>` header, while simultaneously passing `credentials: "include"`.
- **RBAC**:
  - Roles: `user` (default) and `admin`.
  - Admin endpoints ([`/api/admin/*`](file:///home/marshadkhn/Documents/Freelance/Magicteal/dlaven-website/Backend/src/routes/admin.ts)) and admin pages ([`/admin/*`](file:///home/marshadkhn/Documents/Freelance/Magicteal/dlaven-website/Frontend/src/app/admin/page.tsx)) enforce admin role validation.
  - Elevating users: Run `npx ts-node src/makeAdmin.ts <email>` or `src/makeAdminAtlas.ts <email>`.

### 💳 Order Lifecycle & Integrations
- **Cart & Checkout**:
  - Cart state persisted in MongoDB ([`Cart`](file:///home/marshadkhn/Documents/Freelance/Magicteal/dlaven-website/Backend/src/models/Cart.ts)) and synced with frontend state.
  - Multi-step checkout flow: `address` ➔ `confirm` ➔ `pay` ➔ `success/[id]`.
- **Payment Processing**:
  - Razorpay order created via `/api/orders` endpoint.
  - Payment signatures cryptographically verified with `RAZORPAY_API_SECRET`.
  - Order status transitions: `created` ➔ `paid` ➔ `shipped` ➔ `delivered` (or `failed`, `cancelled`, `refunded`).
- **Invoicing & Emails**:
  - Order receipts rendered dynamically into branded PDF documents using PDFKit.
  - Password resets and notifications dispatched via Nodemailer, using either environment credentials or dynamic SMTP settings configured in the database ([`Settings`](file:///home/marshadkhn/Documents/Freelance/Magicteal/dlaven-website/Backend/src/models/Settings.ts)).

### ⚠️ Known Gotchas & Development Constraints

   - In MongoDB, products created under Bérry are tagged `"dl-barry"`. The frontend canonical URL is strictly `/dl-berry`. Do NOT alter this mapping without migrating the database product tags.
2. **Category Tagline / Slogan Rule**:
   - The phrase `"NE DU ELUSIVE PREDATOR"` is standardized across all subcategory explore banners (`clothes`, `jewellery`, `fragrances`) in place of the legacy `"HAUTE PARFUMERIE & ARCHIVAL ELIXIRS"`.

   - `Frontend/src/lib/api.ts` specifically reads `NEXT_PUBLIC_API_BASE_URL`. Do not configure `NEXT_PUBLIC_API_BASE` alone without setting `NEXT_PUBLIC_API_BASE_URL`.
4. **React 19 & Tailwind v4 Ecosystem**:
   - Next.js 16 + React 19 + Tailwind CSS v4 are in use. Be cautious with third-party React component libraries that specify strict peer dependencies on React 18.
5. **CORS Configuration**:
   - Any new staging, preview, or testing domain must be explicitly added to `FRONTEND_ORIGIN` in `Backend/.env` if not matching wildcard rules or IP patterns.
6. **Turbopack Dev Mode**:
   - Frontend runs `next dev`. If encountering cache anomalies during asset manipulation, restart the dev server or clear `.next/`.
