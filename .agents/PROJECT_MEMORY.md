### Key Architectural Patterns
- **Full-Stack Monorepo Structure**:
  - `Backend/`: Express 4 + TypeScript server (`src/server.ts`) connecting to MongoDB via Mongoose.
  - `Frontend/`: Next.js 16 (App Router) + React 19 + Tailwind CSS v4 + Radix UI + Lucide React, featuring 3D animations (Three.js, `@react-three/fiber`, GSAP, Motion).
- **Authentication & Security**:
  - JWT tokens stored in httpOnly cookies (`token`).
  - Role-Based Access Control (`user`, `admin`) enforced via auth middleware (`src/middleware/auth.ts`).
  - Flexible CORS origin validator in `Backend/src/server.ts` supporting IP addresses, comma/JSON-separated origins, and wildcard host suffixes (e.g., `*.vercel.app`).
- **Media, Invoicing & Payments**:
  - Cloudinary integration for image uploads (`/api/uploads`).
  - Razorpay payment gateway integration for orders (`/api/orders`).
  - PDFKit for order confirmation / invoice generation.
  - Nodemailer for password resets and SMTP notifications (configurable via Admin panel Settings model).

### Known Gotchas & Constraints
- **React 19 & Next.js 16 Compatibility**:
  - The frontend relies on React 19 and Tailwind CSS v4. Ensure any added UI libraries are compatible with React 19 peer dependencies.
- **Local Dev Ports & Configuration**:
  - Backend default port is `4000`, frontend default is `3000`.
  - Frontend requires `NEXT_PUBLIC_API_BASE=http://localhost:4000` (in `Frontend/.env.local` or environment) to connect locally.
  - Cookie credentials (`credentials: "include"`) must be passed in fetch calls when querying protected routes.
- **VPS Deployment**:
  - Production deployments are executed via `scripts/deploy.py` or the `/dlavenlive` skill, connecting via SSH to VPS `72.60.221.173` and managing processes with PM2 (`pm2 restart all`).
  - Admin users are ensured during deployment using `src/makeAdmin.ts` and `src/makeAdminAtlas.ts`.

### Key Business Domains & Terminology
- **D’ LAVÉN**: Luxury e-commerce brand specializing in fragrance / lifestyle products.
- **Core Entities**:
  - `User`: Accounts with authentication, shipping addresses, roles (`user`, `admin`).
  - `Product`: Catalog items with pricing, inventory, categories, fragrance notes, and media.
  - `Category`: Hierarchy and groupings for catalog navigation.
  - `Cart` & `Order`: Cart states and lifecycle-tracked customer orders with payment verification.
  - `Code`: Discount / promo voucher codes with redemption rules.
  - `Settings`: SMTP and site configuration editable by administrators.
